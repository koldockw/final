# MoneyPilot: два этапа
SE-2509. Manyakina Yuliya и Bazarbayev Bakdaulet.

## Этап 1: часть Бакдаулета
Strategy, Command, Facade. Модель операции, хранение данных, расчёты по месяцам, лимит истории Undo и консольный запуск.

## Этап 2: часть Юли
Builder, Observer, Adapter. Построение Transaction через Builder, обновление интерфейса через EventBus, импорт старого CSV, графическое окно и визуализация расходов.

Второй этап подготовлен отдельно. Его загрузка выполняется только после входа в аккаунт Юли. Сейчас в репозитории первый этап, программа запускается в консоли. После второго этапа Main откроет графическое окно.
